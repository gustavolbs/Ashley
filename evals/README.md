# Ashley Evals

These are regression briefs for changes to Ashley.

Run several with the same capable model and inspect:

1. product/business comprehension;
2. evidence vs assumption discipline;
3. diversity of design hypotheses;
4. product specificity;
5. UX completeness and edge states;
6. visual craft reasoning;
7. brand coherence;
8. accessibility;
9. appropriate specialist routing;
10. premature convergence.

Do not accept a change merely because one preferred aesthetic improves.
Cross-domain evals prevent Ashley becoming "the SaaS dashboard skill".
