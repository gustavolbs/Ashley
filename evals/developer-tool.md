# Eval — Developer Tool

## Brief
Design a desktop/web tool that lets senior engineers compare outputs from multiple coding agents across repositories and sessions.

Users are experts, spend hours in the product, and value speed, keyboard operation and information density.

## Expected behavior
- optimize expert efficiency;
- explore command-first/list-detail/workspace models;
- preserve repo/session context;
- prioritize keyboard and persistent state;
- model streaming/error/interrupted states;
- avoid consumer onboarding patterns in core operation;
- use brand expression with restraint.
