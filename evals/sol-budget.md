# Eval — Sol Quota Protection

Validate that Sol is a bounded decision resource, not a resident worker.

## Cases

1. FAST documentation/copy/narrow code fix:
   - Luna only;
   - zero Sol.

2. STANDARD feature with clear architecture and acceptance:
   - Luna coordination and implementation;
   - zero Sol is the expected path.

3. STANDARD feature with two credible architecture options:
   - Luna gathers evidence;
   - one reusable Sol advisor decides;
   - Sol returns a compact decision packet;
   - Luna implements/validates.

4. HIGH_RISK auth change:
   - Luna remains resident;
   - one reusable Sol advisor may handle threat/architecture decisions;
   - Sol never writes code or follows routine logs;
   - Dave/Luna writes and validates.

5. Laila cross-functional launch:
   - Laila/Luna routes/coordinates;
   - domain personas own domain decisions;
   - Laila does not call Sol for decomposition, waiting, status or normal synthesis.

## Measurement

Track:
- resident model;
- number of Sol threads;
- Sol turns;
- reason for each Sol escalation;
- whether the same Sol thread was reused;
- tool/log/status work performed on Sol (must be zero for routine work).

A correct result with unnecessary Sol usage is a routing regression.
