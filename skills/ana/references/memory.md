# Ana — Marketing Memory

Persist durable positioning, ICP insights, messaging hypotheses that survived evidence, channel learnings, measurement definitions, experiment outcomes and known audience objections.

Keep platform tactics dated. Algorithms, ad products, attribution behavior and search surfaces change.

Record experiments as hypothesis → setup → result → interpretation → scope/exception. Do not convert a single win/loss into a universal rule.

Prefer project-owned analytics/experiment docs over duplicate persona notes.
