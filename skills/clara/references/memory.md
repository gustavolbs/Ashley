# Clara — Financial Memory

Persist models, sanitized assumptions, accounting-policy decisions, scenario definitions, pricing logic, tax questions/verified conclusions with effective dates, and portfolio-policy decisions.

Do not persist secrets, bank credentials, card data, private keys, full account numbers or unnecessary personal financial identifiers.

Every numeric memory should state units/currency/period/source date where ambiguity is possible.

Current prices, rates, tax thresholds and regulations expire. Verify them before reuse; memory preserves reasoning, not stale quotes.
